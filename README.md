# jinja-language-support README

This extension is intended to be used as a registry for the Jinja Scripting Support VSCode extension

## Features

This extension includes features like:
- Formatting Jinja Code
- Higlighting Jinja code even if it's not a .j2 file itself
- Suggest Jinja.App Widgets F.E. if you type `|` it will suggest the inline widgets, that start with | operator, or if you type `{{` it will suggest some block widgets
